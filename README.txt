KANTA KAMANDALU - READY GAME

HOW TO PLAY
1. Open this folder in VS Code.
2. Install the Live Server extension if needed.
3. Right-click index.html -> Open with Live Server.
4. Press SPACE, click, or tap to fly.

FILES
- index.html = game page
- style.css = design
- game.js = game logic
- images/friend.jpg = flying character
- images/girl.jpg = obstacles

If Live Server says "Forbidden. File does not reside within a trusted folder",
open the entire KANTA-KAMANDALU folder in VS Code using File -> Open Folder,
then right-click index.html and choose Open with Live Server.
